VFX report

Baseplate scans Roblox VFX packs so an agent does not have to guess from titles and thumbnails, and does not pull in malicious code blind.

What safe means here

A pack is listed as safe only for a pinned version, on a stated scan date, under stated scan rules. If the pack changes after that scan, it must be re-checked before it is used at the new version.

Scan rules, in plain language:

  • Hidden require by ID
  • Data exfiltration
  • Obfuscated code that phones home

This list will be updated as scan rules change. A safe result is a scan result for that pinned version, not a guarantee for all future versions.

Safe packs

Safe packs are offered by the Baseplate MCP through find_vfx, with a description, pinned asset ID and version, and scan date. The agent inserts the exact pinned version with the Roblox Studio MCP and strips any scripts in the pack before use.

Scan data status: the safe VFX index format is live in this repo at registry/safe-vfx.json and docs/r/safe-vfx.json, but real scan data has not landed yet. No asset IDs are listed here until that data lands, so this page does not invent safe packs.

When scan data lands, safe packs will be listed here with name, description, asset ID, pinned version, and scan date.

Flagged packs

Flagged packs are never offered by the MCP. They are shown here as warnings only, with the behavior pattern found, not as a way to add them to a game.

Flagged pack details will be listed here when verified scan results land, with the pattern found and the scan date. Creator names are not published from demo artifacts without verified evidence.

Request a re-check

If you think a pack was flagged in error, or a safe pack has changed, request a re-check.

Contact email: to be added by the owner. Until an email is published here, do not send personal account details anywhere for a re-check.

How to use safe packs

Connect Baseplate as an MCP server, then ask your agent to use find_vfx and add_vfx. add_vfx writes a vfx.json lockfile with the pinned asset ID and version.
