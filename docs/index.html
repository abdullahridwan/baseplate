How it works

Three steps. No Roblox experience needed.

01

Your agent connects

Your agent connects once, with one line. You do not set anything up for it.

02

Your agent finds it

Your agent searches Baseplate by description, in text, not thumbnails. You do not need to describe each effect or sound yourself, the agent reads the descriptions, tags, and use cases.

03

It just lands in your game

Baseplate already did the safety work, scanned and pinned it. Your agent just adds it. The files are yours, and you just play.

One example

You say it. Your AI does the rest.

You: Make my game feel rewarding when I pick up coins.

Your AI: Searched the descriptions, found coin_pickup, a bright coin sound, and added it. You did not describe the sound yourself, and there was no thumbnail review and no extra tokens spent hunting for it.

Browse all effects and sounds if you want to see what else is in the library, and read how scanned packs are checked.

Connect your agent

One line, no manual steps beyond that. After that, your AI can find assets the fast, low token way.

Claude Code

claude mcp add baseplate -- npx -y baseplate-cli mcp

Note: this install line requires baseplate-cli 0.3.0 or later on npm. Until it is published, the MCP code is in this repo under cli/.

Codex

[mcp_servers.baseplate]
command = "npx"
args = ["-y", "baseplate-cli", "mcp"]
