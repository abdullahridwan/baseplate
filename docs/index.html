The problem

Your agent rebuilds the same game every time.

Ask a frontier model to "build me an obby" and it spends most of its effort writing systems every obby already has. You pay premium prices for boilerplate, and it comes out a little different, and a little broken, each time.

  • Project layout and loaders every game
  • Saving player data safely every game
  • Secure client to server remotes every game
  • Leaderstats and HUD every game
  • Checkpoints, plots or backpacks every genre
  • What actually makes your game different the part that matters

How it works

Split the work in half.

Every spec is written once with Claude Opus, so every build after it can run on a fast model.

fast model + Baseplate spec

The first 50%: the foundation

Your agent follows an IMPLEMENTATION.md step by step. It doesn't have to design anything, just follow instructions, so a small model gets it right.

  • Data that saves and never wipes
  • Server-side security by default
  • Core genre systems, playable end to end

The last 50%: your game

Theme, mechanics, level design, feel. The expensive model only spends tokens on the part nobody else has built.

  • Built on clear extension points
  • Nothing in the foundation to rewrite
  • Any model, any agent

FAQ

Questions.

What is an IMPLEMENTATION.md?

A Markdown spec your agent follows to build a game system: files to create, the exact Luau to write, and a check after each step. It covers the generic half of a game type and stops where your custom work begins.

Which agents does it work with?

Any agent that can read a file or a URL: Claude Code, Cursor, Codex and others. An MCP server is coming next, so agents can pull specs and steps directly.

Why use a cheaper model for the first half?

Because the design work is already done. Following a precise spec is an easy task, and fast models handle it well at a fraction of the cost. Save the frontier model for the decisions only you can make.

What do I need to get started?

Roblox Studio with API Services enabled, and Rojo 7 or newer to sync code into Studio.

Is it really free?

Yes. Every spec is MIT licensed. Use it, change it, and ship games with it.
