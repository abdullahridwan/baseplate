How it works

  1. 1. Connect once. Add Baseplate as an MCP server to Claude Code, Cursor, or Codex.
  2. 2. Search by description. Ask for what it is for, for example "fire explosion" or "coin pickup". The agent gets a text description, tags, and use cases, not a pile of thumbnails to review.
  3. 3. Add and own it. The agent copies the effect or sound into your project. Once copied, it is yours. You are not dependent on Baseplate staying up.

Safe VFX, not just any VFX

Scanned Creator Store packs are a separate list from the own library above. find_vfx returns only packs with status safe, with a pinned asset ID and version and a scan date.

Flagged packs are never offered by the MCP. They are shown only as warnings on the report page.

Read the VFX report, including scan rules and how to request a re-check.

Connect your agent

Claude Code:

claude mcp add baseplate -- npx -y baseplate-cli mcp

Note: this install line requires baseplate-cli 0.3.0 or later on npm. Until it is published, the MCP code is in this repo under cli/.

Codex:

[mcp_servers.baseplate]
command = "npx"
args = ["-y", "baseplate-cli", "mcp"]

Cursor:

{
  "mcpServers": {
    "baseplate": {
      "command": "npx",
      "args": ["-y", "baseplate-cli", "mcp"]
    }
  }
}

After connecting, ask your agent to call find_vfx, for example: find a safe fire explosion VFX. For scanned packs, add_vfx writes a vfx.json lockfile, then the agent inserts that exact pinned version with the Roblox Studio MCP and strips any scripts.

Free for hobbyists

The component library above is free and open source. Paid premium packs and automation are planned later, not part of V1.

Recipes and implementation specs for building a full game are in the repo under implementations/, but they are not V1 and are not featured here. V1 is the component library.
