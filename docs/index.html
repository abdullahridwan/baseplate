Connect your agent. One line.

Connect Baseplate as an MCP server. One line, no manual steps beyond that. Your agent can then search and add components and safe VFX by description.

Claude Code
claude mcp add baseplate -- npx -y baseplate-cli mcp

Note: this install line requires baseplate-cli 0.3.0 or later on npm. Until it is published, the MCP code is in this repo under cli/.

Codex
[mcp_servers.baseplate]
command = "npx"
args = ["-y", "baseplate-cli", "mcp"]

Put that in your Codex MCP config. The exact config file location depends on your Codex setup, so check your Codex docs if it does not pick it up.

Cursor
{
  "mcpServers": {
    "baseplate": {
      "command": "npx",
      "args": ["-y", "baseplate-cli", "mcp"]
    }
  }
}

Put that in your Cursor MCP settings file. After connecting, ask your agent to call find_vfx, for example: find a safe fire explosion VFX.

Safe VFX only: find_vfx returns only packs with status safe, with a pinned asset ID and version. Malicious packs are never offered by the MCP. See the VFX report for how scanning works.
