How it works

Three steps. No thumbnail hunting, no guessing from a title.

01

Connect once

Add Baseplate as an MCP server to Claude Code, Cursor, Codex, or Windsurf.

02

Search by description

Ask for what it is for, for example "fire explosion" or "coin pickup". You get a text description, tags, and use cases.

03

Add and own it

Your agent copies the effect or sound into your project. Once copied, it is yours.

Safe VFX, not just any VFX

Scanned Creator Store packs are a separate list from the own library above.

  • find_vfx returns only packs with status safe, with a pinned asset ID and version and a scan date.
  • Flagged packs are never offered by the MCP. They are shown only as warnings on the report page.
  • For scanned packs, add_vfx writes a vfx.json lockfile, then the agent inserts that exact pinned version and strips any scripts.

Read the VFX report, including scan rules and how to request a re-check.

Connect your agent

One line, no manual steps beyond that.

Claude Code

claude mcp add baseplate -- npx -y baseplate-cli mcp

Note: this install line requires baseplate-cli 0.3.0 or later on npm. Until it is published, the MCP code is in this repo under cli/.

Codex

[mcp_servers.baseplate]
command = "npx"
args = ["-y", "baseplate-cli", "mcp"]

Cursor

{
  "mcpServers": {
    "baseplate": {
      "command": "npx",
      "args": ["-y", "baseplate-cli", "mcp"]
    }
  }
}

After connecting, ask your agent to call find_vfx, for example: find a safe fire explosion VFX.
