How it works

Every spec is written with Claude Opus, once, so every build after that can be cheap.

01Pick a game type

Obby, tycoon or simulator. Each spec starts from the shared core.

02Your agent builds the base

Steps run in order, each with a "done when" check, so a small model can't drift.

03You build the rest

Every spec ends with extension points: exactly where your 50% plugs in.

> build me an obby from the baseplate spec reading implementations/core/IMPLEMENTATION.md reading implementations/obby/IMPLEMENTATION.md core: 6 of 6 steps done. obby: 6 of 6 steps done. acceptance test passed. > now make it lava themed with a speed-run timer

The specs

Plain Markdown. Point any agent at them: Claude Code, Cursor, Codex. Copy them, fork them, ship with them.

core/

Core

Rojo layout, DataStore saves with retries, rate-limited remotes, service and controller loaders.

 obby/

Obby

Saved stages, anti-skip checkpoints, kill bricks, respawn on your stage, stage HUD.

 tycoon/

Tycoon

Claimable plots, cash, purchase buttons with prerequisites, droppers, a collector, saved progress.

 simulator/

Simulator

Click to collect, backpack capacity, sell zones, upgrades, rebirths and a multiplier.
